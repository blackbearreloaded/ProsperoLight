## Icon prompt

> Create a brand-new square launcher icon for a native PS5 homebrew "Hello
> World" programming example. Stylized game UI icon, centered composition: one
> luminous cyan circle, one vivid magenta triangle, and one warm yellow square
> interlocking into a simple memorable geometric emblem. Deep midnight navy
> background, subtle neon rim light, polished modern 3D/vector hybrid, crisp
> edges, high contrast, readable at very small size, generous safe margins. No
> bear, no controller, no PlayStation symbols, no letters, no words, no
> numbers, no watermark, no border. Output a clean 1:1 square raster image,
> ideally 1024x1024.
